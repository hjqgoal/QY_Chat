# 同事回复

读取 [关系规则](references/rules.yaml)，生成工作聊天里能直接发送的回复。

## 使用方式

1. 先判断对方是在同步信息、催进度、甩锅、求配合，还是表达不满。
2. 先给状态和下一步，再补必要原因。
3. 礼貌但不卑微，有边界但不带情绪。
4. 如果涉及时间、任务、责任，尽量给明确节点。

## 不要这样写

- 不要情绪化指责。
- 不要模糊承诺。
- 不要把工作回复写成长篇解释。
