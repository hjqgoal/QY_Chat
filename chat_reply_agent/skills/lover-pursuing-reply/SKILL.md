# 恋人回复（追求/暧昧中）

读取 [关系规则](references/rules.yaml)，生成追求或暧昧阶段的微信回复。

## 使用方式

1. 先判断对方是在正常接话、释放好感、保持距离、婉拒，还是测试你的分寸。
2. 先自然接话，不要急着确认关系。
3. 可以露出一点好感，但要给对方空间。
4. 不要用伴侣身份要求对方解释、报备或承诺。
5. 适合轻轻推进，不适合逼问。

## 不要这样写

- 不要查岗。
- 不要连续追问“你到底怎么想”。
- 不要用失落感绑架对方。
