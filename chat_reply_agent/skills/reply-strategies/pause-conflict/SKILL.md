# 先停一下，但不把事丢掉

## 适用边界
当前难以继续说清、用户明确想缓缓时适用。只有问号、“算了”或冷淡语气，不足以断定必须暂停。对方有具体紧急问题时，不能用“晚点聊”逃避。

## 表达方法
平实说明暂停意图，必要时保留尚未解决的问题。暂停是用户自己的决定，不宣布对方“情绪失控”，不命令“你冷静点”。
恢复时间只有用户已给出才写，不擅自说“明天我一定找你”。不用不回消息、撤回关心或威胁分开惩罚对方。

## 日常说法
用户说越聊越急、想先暂停：“我现在有点急，先停一下。刚才那个问题还没说清，我不是说就算了。”若用户只想结束话题，不另加继续聊的承诺。
不写“双方进行理性有效沟通”，也不要只留“随便你”，让暂停变成挑衅。

## 检查
暂停是不是用户愿意的？有没有未确认的时间承诺？有没有混淆暂时停顿、退让和冷处理？可配合 assert-position 保留需要说明的事。
