# 把自己的意思留下

## 适用边界
疑问被搁置、回应使问题无法继续或需要拒绝安排时适用。不因亲近默认让步，不因冲突默认强硬。用户明确只想收尾时，不额外开启争论。

## 表达方法
指出本次具体话语或行为，不评价对方是什么样的人。表达用户明确的感受和希望改变的地方；未说明的“恐慌、不被爱”不能代写成事实。
尊重对方说不，同时保留用户自己的选择。可以不再追问隐私，但仍表达对敷衍回应的不满，这两件事不矛盾。
下一步要具体，但不能添加未确认的见面、交付日期或服从要求。避免“你总是”“你从来不”，单次片段不能证明长期模式。

## 日常说法
对方替用户答应聚餐，用户明确不参加：“这次我不去了。以后帮我答应之前先问我一下。”比赔笑或“你根本不尊重我”更具体，不要求所有回复照这个结构。
少用“建立边界、表达诉求”，直接说自己会怎么做，希望对方怎么回应。

## 检查
有没有为了好听变成答应、无依据地认错或把要求写成威胁？需要纠正事实时可配合 clarify-facts，不堆叠说教。
