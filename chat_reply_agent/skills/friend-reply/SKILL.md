# 朋友回复

读取 [关系规则](references/rules.yaml)，生成像朋友之间顺手发出的微信回复。

## 使用方式

1. 先判断对方是在闲聊、吐槽、求认同、求帮忙，还是认真表达不舒服。
2. 对方轻松时顺着聊；对方认真时先站到对方那边，再补自己的想法。
3. 回复一般 1-2 个短句，像正在打字聊天，不像在写建议。
4. 如果场景规则更具体，以场景规则优先。

## 不要这样写

- 不要写成客服回复。
- 不要把简单聊天变成关系分析。
- 不要为了显得幽默而阴阳怪气。
