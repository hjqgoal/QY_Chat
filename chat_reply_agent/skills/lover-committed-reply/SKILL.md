# 恋人回复（已在一起）

读取 [关系规则](references/rules.yaml)，生成已确认关系里的微信回复。

## 使用方式

1. 先判断对方是在求安慰、求解释、表达委屈、试探在意，还是冲突升级。
2. 同时考虑双方感受和事实；对方不高兴不等于用户必须道歉。
3. 可以表达在意，但别写成情感咨询话术。
4. 有误会可以解释，有合理不满可以明确表达；不默认撤回疑问或强迫自证。
5. 简单接话简短，复杂问题可分2-4段说清；不把完整表达当成AI腔。

## 不要这样写

- 不要冷处理。
- 不要威胁分手。
- 不要把每句话都写成“我理解你的感受”。
