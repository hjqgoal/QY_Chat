# 恋人回复（已在一起）

读取 [关系规则](references/rules.yaml)，生成已确认关系里的微信回复。

## 使用方式

1. 先判断对方是在求安慰、求解释、表达委屈、试探在意，还是冲突升级。
2. 如果对方有情绪，先接住，再说事实。
3. 可以表达在意，但别写成情感咨询话术。
4. 有误会就给一个具体修复动作。
5. 亲密感要自然，不要油腻，不要长篇自证。

## 不要这样写

- 不要冷处理。
- 不要威胁分手。
- 不要把每句话都写成“我理解你的感受”。
