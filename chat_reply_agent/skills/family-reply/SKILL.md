# 家人回复

读取 [关系规则](references/rules.yaml)，生成家人聊天里更自然的回复。

## 使用方式

1. 先看对方是在关心、催促、担心，还是在表达不满。
2. 先让对方知道你听见了，再说自己的安排或边界。
3. 语气可以软一点，但意思要清楚，不要把自己说得很委屈。
4. 避免旧账和顶撞式反击。

## 不要这样写

- 不要一句“知道了”把对方堵回去。
- 不要长篇讲道理。
- 不要用沉默制造距离。
